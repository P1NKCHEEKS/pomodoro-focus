# Pomodoro Focus

Расширение для Visual Studio Code, которое помогает работать по технике Pomodoro: 25 минут работы, затем 5 минут отдыха. Оставшееся время показывается в строке состояния, а об окончании интервала расширение сообщает уведомлением.

Написано на чистом JavaScript, без сторонних npm-пакетов и этапа сборки.

**[Сайт документации](https://p1nkcheeks.github.io/pomodoro-focus/index.html)** — HTML-справочник по коду расширения, сгенерированный из JSDoc-комментариев.

## Возможности

- Таймер рабочей сессии на 25 минут.
- Таймер перерыва на 5 минут.
- Пауза и возобновление.
- Сброс таймера.
- Обратный отсчёт в строке состояния.
- Уведомление об окончании сессии или перерыва.

## Требования

- Visual Studio Code версии 1.80.0 или выше.

## Команды

Откройте палитру команд: `Ctrl+Shift+P` (Windows/Linux) или `Cmd+Shift+P` (macOS).

| Команда | Что делает |
|---|---|
| `Pomodoro: Start Focus` | Запускает отсчёт |
| `Pomodoro: Pause / Resume` | Ставит таймер на паузу или возобновляет его |
| `Pomodoro: Start Break` | Начинает 5-минутный перерыв |
| `Pomodoro: Reset` | Останавливает таймер и возвращает 25:00 в режиме фокуса |

Щелчок по таймеру в строке состояния тоже запускает отсчёт.

## Строка состояния

Формат: `<режим> ММ:СС`.

| Пример | Значение |
|---|---|
| `🍅 Focus 24:59` | Идёт рабочая сессия |
| `☕ Break 04:30` | Идёт перерыв |
| `🍅 Focus 12:00 ⏸` | Таймер на паузе или остановлен |

## Уведомления

| Когда | Сообщение |
|---|---|
| Закончилась рабочая сессия | `Focus session finished! Time for a break.` |
| Закончился перерыв | `Break finished! Ready to focus?` |
| Таймер уже запущен, а команда Start вызвана снова | `Pomodoro timer is already running.` |
| Выполнен сброс | `Pomodoro timer reset.` |

## Запуск для разработки

1. Откройте папку проекта (ту, где лежит `package.json`) в VS Code.
2. Откройте **Run and Debug**.
3. Выберите **Run Pomodoro Focus (Extension Development Host)**.
4. Нажмите `F5`.
5. В новом окне откройте палитру команд и выполните `Pomodoro: Start Focus`.

## Известные ограничения

- После окончания сессии перед новым запуском нужно выполнить `Pomodoro: Reset`, иначе таймер сразу завершится.
- После окончания перерыва режим остаётся «Break» до сброса.
- Длительности интервалов заданы в коде и не настраиваются.
- Состояние таймера не сохраняется между запусками VS Code.
