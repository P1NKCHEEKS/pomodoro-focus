# Техническое задание

**Плагин:** Pomodoro Focus
**IDE:** Visual Studio Code
**Язык:** JavaScript

## Назначение

Таймер по технике Pomodoro внутри редактора: 25 минут работы, затем 5 минут отдыха. Время всегда видно в строке состояния.

## Функциональные требования


 - Команда `Pomodoro: Start Focus`  запускает обратный отсчёт с текущего значения. Если таймер уже идёт, показывается уведомление и состояние не меняется |

 - Длительность рабочей сессии — 25 минут, перерыва — 5 минут |

 - Команда `Pomodoro: Pause / Resume`  ставит идущий таймер на паузу, сохраняя оставшееся время, а остановленный возобновляет

 - Команда `Pomodoro: Start Break`  прерывает текущий отсчёт, переключает режим на перерыв и запускает 5-минутный отсчёт 

 - Команда `Pomodoro: Reset`  останавливает таймер, возвращает режим фокуса и значение 25:00, показывает уведомление 

 -  В строке состояния (слева) отображается `🍅 Focus ММ:СС` или `☕ Break ММ:СС`, значение обновляется раз в секунду. Если таймер не идёт, добавляется значок ⏸ 

 - Щелчок по элементу в строке состояния запускает отсчёт 

 - По окончании рабочей сессии показывается уведомление `Focus session finished! Time for a break.`, по окончании перерыва — `Break finished! Ready to focus?`
